Type: reference.

The inventory owns scenario counts and criterion links. Check definitions own
requirements and their pass meanings. These tables are generated during the docs
build; they contain no model results.

<!-- benchmark:coverage -->

Review a check's requirement basis before treating it as a safety standard.
A caregiver instruction, a supplied source, and an authored conversational
preference carry different authority. Development controls exercise the authored
boundary. Independent validation must test whether the evaluator recognizes it
on unseen evidence.

Read the [check grammar](https://github.com/givecareapp/givecare-bench/blob/main/checks/README.md)
and the [validation protocol](validation.md).
