# Shared workpad

> A living document for humans and agents. The page stays readable; its trail stays inspectable.

## Current frame

We are shaping one Workpad codebase with two isolated instances:

- **Helm / Open** — private thinking, durable wiki promotion, agent handoffs.
- **GiveCare / Review** — invited collaborators, review decisions, shared drafts.

## Working agreement

Edit the document directly. Use the activity rail for reasoning that should remain visible without cluttering the page. Every save records its actor and exact before/after revision.
